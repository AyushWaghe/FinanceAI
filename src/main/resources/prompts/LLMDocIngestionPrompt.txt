Perform the following tasks in the SEQUENTIAL exact order.

Compare the uploaded document with the user-provided description.
Determine whether the description accurately represents the document.

{
  "verified": false,
  "reason": "<Brief explanation of why the document does not match the description>"
}

TASK 2: DOCUMENT ANALYSIS

If the document is verified:

1. Identify the document type.

- salary_slip
- bank_statement
- offer_letter
- invoice
- tax_document
- insurance_policy
- investment_statement
- identity_document
- utility_bill

2. Recommend exactly ONE chunking strategy from:
- PAGE
- DOCUMENT
- SEMANTIC

Which you think will be appropriate from the above given options
3. Generate a concise one-line summary (maximum 20 words).

OUTPUT FORMAT-:
Return ONLY valid JSON.

Successful response:

  "verified": true,
  "documentType": "...",
